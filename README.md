# Tic-Toe-Game


  This is a classic two-player Tic-Tac-Toe game built with HTML, CSS, and JavaScript.
  
  Features:
  - Interactive 3x3 grid for gameplay
  - Turn-based logic for players X and O
  - Game status display: player turns, win, or tie
  - Responsive design for both desktop and mobile devices
  - Reset button to restart the game anytime
  - Light and Dark theme toggle for better user experience
  
  Players take turns clicking on empty cells to place their symbol (X or O).
  The game automatically checks for a win condition (row, column, or diagonal)
  or a tie when all cells are filled. Users can switch between themes using the
  dedicated buttons.
